# ProbeFlow V1.1 开发与验收计划

依据：`AI_INTERVIEW_V1_SPEC.md` V1.1；目标是完成全文要求，不以模拟通过替代真实接口、真人和设备验收。

## 全局约束

- React、TypeScript、Vite；Python 3.12+、FastAPI、Pydantic、SQLAlchemy、Alembic、SQLite；FFmpeg。
- 单个应用进程、持久任务、事件轮询、最多 2 场活动访谈；不引入额外任务队列服务。
- 正式档案永久保存；主动删除／撤回仍有效；真实资料、密钥和备份不进入仓库。
- 模拟／真实模式严格区分；中文界面；同意、身份、会话作用域和预算由服务端控制。
- 每个模块先建立行为测试并观察失败，再实现；所有验收记录注明证据及未实测项。

## 任务及首阶段验收

1. **M0 基础与契约**：建立项目、锁文件、配置校验、数据迁移、单管理员认证、不可变研究版本、限定会话和同意记录。首阶段验收：无 API 密钥可启动；新建研究、邀请、同意、文字回答能持久化；不同意与越权均拒绝；正式档案期限配置被拒绝。
2. **M1 访谈与报告**：结构化访谈决策校验、上下文压缩和引用、20 个固定案例、持久模型任务、机器及人工修订、可追溯报告、JSON／Markdown／CSV 导出。
3. **M2 音频与供应商**：检测录音格式、IndexedDB 暂存、分块及幂等、FFmpeg 探测／拆分、百炼 ASR／文字／TTS／报告四角色、确认与播放状态、永久资产。
4. **M3 恢复与预算**：租约和重启恢复、重试及未知计费、月度与场次原子预算预占、活动时间与 90 分钟安全边界、存储不足、清理安全条件。
5. **M4 权限与删除**：邀请兑换、恢复邀请、CSRF／限速／媒体鉴权、已完成会话撤回、删除清单、并发任务保护、HTTPS 部署说明。
6. **M5 交付**：五个页面完整联调；自动验收 A01—A21；虚构数据备份恢复演练；浏览器端到端测试；真实接口及访谈质量、60 分钟、三类设备验收；形成结果清单、限制和简单使用说明。

## 模块分工与集成

- 主执行者负责配置、数据库、API、持久任务、预算、存储、备份和全系统集成。
- 独立实现者负责供应商／媒体工具、访谈策略／报告校验、前端；只编辑分配的目录并提交可重复测试证据。
- 对外契约见 `docs/api-contract.md`；所有契约变动先同步后集成。
- 各模块完成后审查规格覆盖与质量；最后进行整体审查，修复真实缺陷并重新验证。

## 验收证据

自动检查和实际运行结果写入 `docs/acceptance-results.md`；外部条件缺失的验收明确待测。当前环境没有百炼 API 凭证，真实调用待本机配置；真人和 iPhone／Android 验收需真实设备及参与者，不能由仿真替代。

## 决策记录

- 在当前专用项目目录的 `codex/v1.1-implementation` 分支开发；仓库原先仅有规格书，避免建立重复工作目录导致用户找不到运行入口。
- 现有规格的 M0—M5 是本次完整开发授权的实施依据，不再逐阶段请求重复许可。
- 供应商为规格指定的阿里云百炼，不创建 OpenAI 密钥、不自动切换供应商；接入参数按官方文档复核。

## 追加验收边界（2026-09-16）

- 访谈中的回答方式可切换；文字首次启用语音须补充主动同意，已有语音授权可逐轮改用文字。同页切换保留草稿，录音或未完成处理时禁止切换；未完成上传只能恢复，或经明确确认重新回答。组件测试和模拟页面操作已验证，真实麦克风失败与手机恢复仍单列设备验收。
- 历史输出来源必须独立于运行配置：切换模拟／真实模式、修订文字、任务重试、备份恢复后仍能区分 mock/live/mixed/unknown，缺少历史信息时明确来源未确认。
- 邀请管理包含列表、撤销未兑换邀请、到期拒绝和已结束会话恢复；撤销邀请或更换访问凭证不得删除档案。
- 已完成场次需要新处理授权时，提供补充同意入口，保留原同意历史，不重新开始访谈或自动执行处理。
- 报告保留生成时研究背景、主题覆盖及来源快照；六类发现分别展示，缺乏依据时明确留空。提前结束、待确认文本及音频缺失／损坏由程序加入局限，模型不能删去。跳过边界在接收操作时立即保存。
- 长报告分段读取全部确认来源，再分层汇总；汇总引文只能复用已提取证据，格式修复最多一次并独立记账。任务重试复用同一来源快照，期间勘误标记来源已更新。
- HTTPS 部署文档与可信代理配置已经提供；真实域名、证书与远程录放音仍须按部署文档验收，不以配置示例代替上线证据。
- 同意历史可在管理页及 JSON 完整导出中核对，研究与提示词版本使用场次绑定的历史值。启动／每日维护的完整档案时间测试已覆盖 8 天、91 天及 10 年模拟年龄；强制中断进程矩阵与真实长会话仍单列验收。
- 报告中断的两个进程边界已实测：请求在途时等待人工费用确认，结果检查点提交后复用已保存响应；资料不丢失，不重复调用。报告重试与新建的费用确认必须由后端根据持久状态校验，不能依赖页面内存；原始录音写入／资产登记、撤回清单持久化／数据库删除提交四个中断点也已验证，重启恢复原音频或完成删除，旧备份不能复活撤回内容。上传文件写入／块登记／识别提交但响应未到达的三个中断点已验证重试不重复处理；进程终止不等于机器断电。
- 导出追溯信息覆盖 CSV／Markdown 的历史研究、提示词和模型、时间、确认标记及修订关系；稳定引用 ID 关联全部报告与指定文本修订。JSON 保留全部报告正文，Markdown 正文展示最新报告并附全部版本引用索引。元数据同样执行公式／Markdown 防护。
- 受访者任务读取和重试限定为 decide／asr／tts，报告由管理员发起与重试；补测真实存在资源的跨场次读写、Range 音频、事件及角色凭证边界。
- 研究删除在清单持久化和数据库提交后分别强制中断，验证全部场次、邀请与提纲任务被清除且旧备份不能复活。即使关闭后台任务，启动也必须先完成删除一致性处理。真实设备和界面故障场景仍需单独验收。
