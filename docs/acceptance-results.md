## 浏览器实测

Codex 内嵌桌面浏览器、本机同源 HTTP、模拟模式：完成管理员登录、创建与发布研究、单次邀请兑换、文字模式主动同意、回答及修改确认、下一问、暂停、刷新恢复、结束保留和报告展示。重启服务后可再次读取原场次。

本轮还在浏览器验证邀请创建、列表状态与撤销，已兑换场次仍可访问；历史来源缺失时明确提示来源未确认。已结束场次更新说明后可补充授权，两项默认未选，提交后仍停留在结束页；研究者随后生成的报告 V2 成功完成，并保留混合来源标识及原有报告 V1。

新增报告 V3 的浏览器检查：研究局限置于报告前部，展示提前结束、文字输入和未核实陈述；研究背景、主题覆盖及六类发现分开显示，缺乏依据的分类明确留空。点击引用展开指定的文本版本 2，并高亮对应原文。旧报告 V1／V2 保留，旧版没有保存的背景与覆盖快照明确标为缺失。

同意历史的浏览器检查：展开“同意与保存记录”可查看两次已接受记录的时间、说明版本、输入方式、两项同意及保存策略。早期记录缺少处理方快照时明确说明；后续模拟授权展示当时保存的处理配置，未用当前配置补写历史。

报告重试的浏览器检查：重新打开预设为模拟请求中断的虚构场次后，处理记录仍显示费用未知，确认框默认未选且重试按钮禁用。勾选后重试原任务，生成按钮在排队期间禁用，轮询后报告 V1 和原处理记录均显示完成，逐字稿仍可见。本检查未向真实供应商发送请求。

回答方式切换的浏览器检查：文字回答中输入虚构草稿，选择语音后显示补充说明，两项同意默认未选且提交禁用；取消后草稿完整保留。再次进入并主动接受后出现语音回答入口，切回文字仍保留原稿，可提交、确认并生成下一问。管理端保留文字、语音两次同意的版本、时间和永久保存策略，以及该文字回答的原始与确认版本。此次未点击录音或授予麦克风权限；录音器失败和暂停后的恢复入口由组件测试验证，不能据此认定真实设备录音通过。

报告引用能展开对应的文本版本；原始输入和确认文本同时可见。诊断试听任务能从处理中转为完成并返回音频控件。**点击原生播放控件时，内嵌浏览器页面崩溃，播放是否成功未确认，根因待定位。** 尚未取得真实桌面麦克风、Android Chrome、iPhone Safari 的录放音证据；界面测试不能替代这三项。

## 备份恢复演练

执行 `.venv/bin/python scripts/acceptance_drill.py`。脚本强制模拟模式，在仓库外临时目录生成两场虚构语音访谈，保存原始音频、机器转写、确认与研究者勘误、两个报告版本，备份后删除其中一场，再恢复到独立空目录。

## 本轮修复与回归边界

- 为录音、机器文本、人工修订、模型问题和报告保存来源快照。`test_archive_provenance` 验证模拟转真实后不改写历史标识、人工勘误保留输入来源、复用任务检查点保持旧供应商／模式、缺少来源时明确 unknown。JSON／CSV／Markdown 和管理页使用档案来源，运行模式单独展示。
- 邀请管理仅允许撤销未兑换邀请；已兑换后通过恢复邀请轮换访问凭证。列表不返回 token 或哈希，撤销及恢复不删除档案。
- 已完成场次可补充新版本同意，不重开访谈、不自动执行任务。新处理仍须有效授权，拒绝新说明不影响既有档案读取与导出。
- 报告新增研究背景与覆盖快照、六类发现和固定观察局限。跳过后立即结束也保留拒答边界；只提问、旧版证据和已修改的来源不能显示为已覆盖。报告的局限包含提前结束、未确认文本及真实音频缺失／损坏原因。
- 报告任务首次处理冻结来源版本；分段提取后分层汇总，汇总只能复用已校验的精确引文。格式或引文失败仅修复一次并分别记账，失败不发布。长报告测试覆盖 3 段约 1.5 万字来源、汇总超时、人工重试及期间勘误；已完成提取未重复调用，新报告标记来源更新。当前汇总输入超过 64,000 字符会明确失败并保留原档案，不截断来源；真实长会话质量仍待验证。
- HTTPS 启动参数默认不信任转发头，仅可指定明确代理 IP，拒绝通配符；自动测试核对默认值与显式配置。未实际部署域名或签发证书。
- 人工重试报告结构失败时会替换该失败步骤的无效缓存，避免反复读取同一无效结果；已完成步骤与来源快照继续复用。回归测试先复现旧行为，再验证重试生成成功、账本保留三次请求、期间勘误不会替换原引用。
- 管理页及 JSON 完整导出新增同意历史和不可变研究版本信息。导出提示词版本从该场研究版本读取，不再写死当前版本；改变研究目标或供应商配置不改写旧授权快照。受访者响应仍不包含管理端的同意历史列表。
- 完整档案时间测试经过真实应用生命周期及每日维护入口，使用独立临时目录和模拟音频；不等同于强制终止进程或真实 60 分钟设备验收。
- 报告费用确认由服务端按持久任务校验；管理页刷新后仍提示未知费用，并恢复活动任务轮询。提供原报告任务重试，复用已完成步骤；跨场次、非报告和失效授权不能借此触发处理，同时阻止重复排队。
- 强制中断测试实际启动并终止测试专用子进程：请求进行中时，重启保留一条未知费用记录且不自动调用；响应检查点已提交时，重启复用响应并生成带原引用的报告，账本不重复。发现并修复中断报告让会话一直停在 finalizing 的问题；重启后会话完成、资料可导出，报告等待人工确认。其他访谈请求未知时暂停并只发出一次持久失败事件。
- CSV／Markdown 补充冻结研究版本、提示词版本、历史模型调用、创建及导出时间、机器／人工确认标记和修订关系。JSON／管理端引用新增持久引用 ID；CSV 引用索引关联全部报告版本，Markdown 展示最新正文与全部报告的引用索引。未知历史模型明确未记录，不按当前配置补写；新元数据同样执行转义。
- 原始录音在写入文件后、提交资产记录后分别强制中断测试专用进程；重启只执行一次模拟识别，保留原始音频哈希且不产生重复资产。即使上传块已超过临时文件期限，启动清理也不会破坏恢复；转写完成后清理上传块仍可回放完整原录音。
- 撤回在删除清单持久化后、数据库删除提交后分别中断；启动先完成内容、音频、任务及凭证清理。旧凭证失效、旧备份不能恢复已撤回场次，另一场次逐项不变。这是进程终止测试，不是机器断电或介质故障测试。
- 受访者重试接口原先允许同场任何失败任务，现仅允许 decide／asr／tts，报告重试必须使用管理员接口。回归保留长报告的冻结来源、成功步骤复用及未知费用确认；旧测试改用实际管理端路径，并增加受访者被拒断言。受访者任务列表使用同一允许列表。
- 上传应用在写入音频块文件、提交块记录、创建识别任务而响应尚未送达时分别被终止；重新启动并重复请求后，只产生一个识别任务、一个音频资产、一版机器文本和一条账本。未完成的旧上传块仍可恢复；哈希冲突继续拒绝。测试使用本机 ASGI 请求和模拟识别，不能替代真实浏览器断网试验。
- 研究删除中断覆盖已保存录音的场次、待同意场次、未兑换邀请及待执行提纲任务，另一个研究保持不变。发现并修复关闭后台任务启动时跳过删除清单的问题；无论后台任务开关如何，都先完成待删除资料和文件清理，再开放请求。旧备份继续过滤该研究全部内容。
